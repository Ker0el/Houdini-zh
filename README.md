# Houdini 界面中文词条库

Houdini 22.0.368 界面文案的中英对照**词条数据**。

这个仓库只有数据，没有程序。词条按「英文原文 → 中文」成对存放，
谁想拿去做自己的中文界面、或者只想查某个术语 Houdini 里是怎么叫的，都可以直接用。

```
词条        46,812 条
正则规则        71 条     运行时拼出来的文案，如 "12 nodes cooked"
前缀规则         7 条     如 "Undo Cutting" / "Unable to undo ..."
排除表       1,803 条     本来就不该翻的（标识符、库名、文件格式名…）
```

## 目录

```
dict/zh_cn.json        成品。程序读的就是这一份
dict/tpl_base.json     模板标签的基础名（Add / Clamp / …），展开后并入成品
dict/batchNN.json      分批源文件，按加入顺序编号，用来追溯每条的来历
```

`zh_cn.json` 是**生成的**——由 `batchNN.json` 依次合并、后面的覆盖前面的。
改词条请改对应的 batch 文件再重新合并，别直接改成品，否则下次合并会被盖掉。

## 数据格式

```jsonc
{
  "_meta": { "app": "Houdini 22.0.368", "language": "zh-CN" },

  // 键 = 界面上的英文原文（原样，含 & 加速键和 ... 省略号），值 = 中文
  "Start Frame": "起始帧",

  // 运行时拼出来的文案，带捕获组
  "patterns": {
    "^([0-9]+) node copied$": "$1 个节点已复制"
  },

  // 前缀规则：命中前缀后，剩下的部分再查一次词典
  "prefixes": {
    "Undo ": "撤销 "
  },

  // 明确不翻的。放进这里就不会出现在缺口报告里
  "skip": ["USD", "VEX", "Blosc"]
}
```

以 `_` 开头的键是元字段，不会被当成词条。

## 翻译约定

写新词条前请先看这几条，都是踩过坑总结出来的：

**一个词只有一种译法。** `Lighting` 不要这儿写「照明」那儿写「灯光」。
高频领域词（Lighting / Volume / Density / Mask / Domain…）尤其要统一。

**成组的值必须对称。**
`Lit` / `Unlit` 要译成「受光」/「不受光」，不能一个「受光」一个「未点亮」——
一组值用了两个不同的比喻，摆在一起非常怪。
同类还有 `On/Off`、`Enabled/Disabled`、`Show/Hide`、`Add/Remove`。

**同义词不要译成同一个中文。**
`Delete` 和 `Remove` 如果都译成「删除」，下游按文本分发就会撞车。
一个译「删除」，另一个译「移除」。

**别翻标识符。**
节点类型名、参数名、属性名、Python 回调名（`onStart`、`string::StartsWith`、
`aov_*`、`*.gad`）既是界面文字又是查询键，翻了会坏事 —— 这类直接进 `skip`。

**数字开头的判断要小心。**
「数字开头就不翻」会把 `2D Viewport` 整条误伤。正确判据是
**数字开头且字母少于 3 个**。

**别信机翻的专业词。** DeepL 会把 `Domain` 译成「域名」（仿真里是**模拟域**）、
`Step Once` 译成「第一步」（应是**单步**）、`divert the flow` 译成「改变水流方向」
（烟/火仿真里是**流动**方向）。中文读着通顺 ≠ 翻对了，要对着英文逐条核。

## 加词条

在 `dict/` 下新建 `batchNNN.json`（编号接着最后一个来），格式：

```json
{
  "note": "这批是什么场景下发现的",
  "entries": [
    ["English Source", "中文译文"]
  ],
  "patterns": {},
  "prefixes": {},
  "skip": []
}
```

四个字段都可以只有一部分。写完之后：

1. 检查 JSON 是合法的，且**不含重复键**（重复的后者会静默覆盖前者）
2. 按编号顺序合并进 `zh_cn.json`（后合并的覆盖先合并的）
3. 确认 `zh_cn.json` 里没有残留的本机路径 —— 环境变量面板、Python 报错面板
   会把整张环境变量表和 traceback 连路径一起带进来，那些永远匹配不到别人机器，
   只会泄露你自己的目录结构
